# 実装コードの入口

ユーザーの自作・改造コードを、使っていない試作も含めて保全します。現在取得できているアプリケーションは [PS4 Eyeの6本](ps4-eye/README.md) です。LLMは外部プロジェクト全体を転載せず、[patches](../patches/README.md) でローカル変更と試作差分を復元します。調査・保全・検証のコードは [scripts](../scripts/README.md) へ分けています。

原本は非公開保全先に残しています。公開コピーは整形・リファクタリングせず、固定ユーザー名が含まれる1本だけ公開用パスplaceholderへ置換しました。変更理由と両方のSHA-256は [code-origins.json](../reference/code-origins.json)、全コード出現の判定は [棚卸し](../reference/code-inventory.md) にあります。

校正データ、撮影画像、firmware、モデルはコードとは別資産です。このディレクトリに入れません。公開されたコードを置いたことは、カメラ取得や深度精度の実機検証を済ませた意味ではありません。包括ライセンスは未設定で、[LICENSE](../LICENSE) の適用範囲を参照してください。
